# Use Case 3: Remote Tech-Team "Hype & Health" Dashboard

An internal dashboard tracking software engineering team sprint performance velocities combined with real-time wellness metrics indicators to prevent burnout.

## Technology Stack Alignment
- **Backend Core Architecture:** .NET 8.0 Web API (Entity Framework Core Code-First)
- **Database Engine Infrastructure:** Local SQL Server Instance (LocalDB)
- **Frontend App Implementation:** Angular 21 Standalone Components
